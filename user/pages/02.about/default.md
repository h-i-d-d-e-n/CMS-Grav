    <h2>Our Project</h2>

    <p>
        The website brings together information, stories and useful resources
        in a simple and organized environment. Our goal was to create
        something that feels like a real website while also demonstrating
        how a content management system can be used to manage and present
        information.
    </p>

    <p>
        Behind the website is Grav, an open-source flat-file content
        management system. Grav was chosen because it provides a lightweight
        approach to managing website content while still allowing extensive
        customization.
    </p>

    <hr>

    <h2>Why Grav?</h2>

    <p>
        Unlike traditional content management systems, Grav does not require
        a database to store the main website content. Pages are stored as
        files, making the system lightweight and relatively easy to move,
        back up and manage.
    </p>

    <p>
        Grav also separates content from presentation. Pages contain the
        website information, while themes control how that information is
        displayed to visitors.
    </p>

    <h3>Simple. Flexible. File-based.</h3>

    <p>
        This approach makes Grav suitable for projects where simplicity and
        flexibility are important. Developers can work directly with the
        website files while content can also be managed through the
        administration interface.
    </p>

    <hr>

    <h2>Our Design</h2>

    <p>
        The website uses the <strong>Antimatter</strong> theme as its
        frontend foundation. The original appearance was customized to
        create a darker and more modern visual style.
    </p>

    <p>
        CSS was used to customize the colors, navigation, forms, buttons,
        typography and other elements of the interface. The homepage also
        includes a full-width visual banner.
    </p>

    <h2>Plugins</h2>

    <p>
        One of the advantages of Grav is its plugin system. Plugins can
        extend the functionality of the CMS without requiring every feature
        to be developed from scratch.
    </p>

    <h3>Form Plugin</h3>

    <p>
        The Grav Form plugin is used on our Contacts page. It provides the
        functionality needed to create and process the contact form.
    </p>

    <p>
        This demonstrates how additional functionality can be added to a
        Grav website through plugins.
    </p>

    <hr>

    <h2>Administration</h2>

    <p>
        Website content and settings can be managed through the Grav
        administration interface. The administrator can create and edit
        pages, manage plugins, configure the theme and control other
        aspects of the website.
    </p>

    <p>
        The administration panel for this project is available at:
    </p>

    <p>
        <strong>/admin</strong>
    </p>

    <p>
        Administrator login credentials are used to access the panel.
        They are kept private rather than displayed publicly on the website.
    </p>

    <hr>
