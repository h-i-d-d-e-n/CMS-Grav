    <h1>Welcome to My Website</h1>

    <p>
        Welcome to my website, created as a practical demonstration of a
        working content management system. This project was developed using
        Grav, an open-source flat-file CMS designed to provide a simple,
        flexible and lightweight way of managing website content.
    </p>

    <p>
        The purpose of this website is to demonstrate how a modern website
        can be created, organized and maintained using a content management
        system without relying on a traditional database.
    </p>

    <hr>

    <h2>A Working Content Management System</h2>

    <p>
        A content management system, commonly known as a CMS, provides tools
        that allow users to create, edit, organize and publish content.
        Instead of manually editing every page of a website, a CMS provides
        a structured environment where content can be managed more easily.
    </p>

    <p>
        This website demonstrates several of the basic ideas behind a CMS.
        Pages can be created and modified through the administration panel,
        navigation can be organized, themes can change the appearance of the
        website, and plugins can extend the functionality of the system.
    </p>

    <h3>Why Use a CMS?</h3>

    <p>
        Websites often contain many different types of information. News
        articles, contact information, project descriptions and other
        content need to be organized in a logical way. A CMS makes this
        process easier by providing a central system for managing that
        information.
    </p>

    <p>
        Another advantage is that the appearance of a website can be
        separated from its actual content. This means that the design can be
        changed without having to completely rewrite every page.
    </p>

    <hr>

    <h2>About This Project</h2>

    <p>
        This website was created as part of a Content Management Systems
        Programming project. The project demonstrates the installation,
        configuration and customization of an open-source flat-file CMS.
    </p>

    <p>
        The website contains several sections that demonstrate different
        aspects of the system. The <strong>News</strong> section is used for
        publishing articles and updates. The <strong>About Us</strong>
        section contains information about the CMS, the selected theme and
        installed plugins. The <strong>Contacts</strong> section provides
        information and a contact form.
    </p>

    <h3>Website Structure</h3>

    <p>
        Good organization is an important part of website development.
        Content has been separated into individual pages so that visitors
        can easily find the information they are looking for.
    </p>

    <ul>
        <li>Home - the main introduction to the website.</li>
        <li>News - articles, updates and other information.</li>
        <li>About Us - information about the project and CMS.</li>
        <li>Contacts - contact information and a contact form.</li>
    </ul>

    <hr>

    <h2>What Makes Grav Interesting?</h2>

    <p>
        One of the main characteristics of Grav is that it is a flat-file
        content management system. Instead of storing website content in a
        traditional relational database, Grav stores content in files.
    </p>

    <p>
        This approach can make a website easier to move, back up and manage.
        The website content exists as files within the project structure,
        which also makes it convenient for developers to work with the
        website directly.
    </p>

    <h3>Simple Content Management</h3>

    <p>
        Grav uses Markdown for much of its content structure, while also
        allowing HTML to be used when additional control is required. This
        makes it possible to create simple pages quickly while still
        allowing more complex layouts when necessary.
    </p>

    <h3>The Administration Panel</h3>

    <p>
        The administration interface provides a graphical environment for
        managing the website. Pages, plugins, themes and other settings can
        be accessed from the administration panel.
    </p>

    <p>
        This means that the website does not have to be managed entirely
        through code. Content can be edited through the CMS while the
        underlying files remain available for more advanced customization.
    </p>

    <hr>

    <h2>Themes and Design</h2>

    <p>
        Themes are responsible for the visual presentation of a Grav
        website. They control how pages are displayed and provide the
        templates, styles and other resources used by the frontend.
    </p>

    <p>
        For this project, the default frontend appearance was changed by
        using a different theme. This demonstrates that the same website
        content can be presented using a different visual design without
        changing the basic purpose of the website.
    </p>

    <h3>Customisation</h3>

    <p>
        A CMS becomes much more useful when its appearance and functionality
        can be adapted to the needs of a particular project. Themes can be
        customized through their templates and CSS, while plugins can add
        additional functionality.
    </p>

    <hr>

    <h2>Features Demonstrated on This Website</h2>

    <p>
        The website demonstrates several common features that can be found
        in a content management system:
    </p>

    <ol>
        <li>Creation and management of individual pages.</li>
        <li>Organization of content through navigation.</li>
        <li>Use of a frontend theme.</li>
        <li>Theme customization.</li>
        <li>Plugin-based functionality.</li>
        <li>News and article publishing.</li>
        <li>Contact information and a contact form.</li>
        <li>Management through an administration interface.</li>
    </ol>

    <h3>Content Management</h3>

    <p>
        Content can be updated as the website develops. New articles can be
        added, existing information can be edited and unnecessary pages can
        be removed. This makes the CMS suitable for websites where content
        changes regularly.
    </p>

    <h3>Extending the Website</h3>

    <p>
        Plugins provide another way of extending a CMS. Instead of building
        every feature from scratch, additional functionality can be added
        through existing plugins. This makes the development process more
        flexible and allows the website to grow over time.
    </p>

    <hr>

    <h2>Looking Ahead</h2>

    <p>
        A website is rarely a finished product. Content can continue to
        change, new pages can be added and the design can be improved as
        requirements develop.
    </p>

    <p>
        This project provides a basic example of how an open-source flat-file
        CMS can be used to create a complete website with structured
        navigation, articles, custom design and additional functionality.
    </p>
